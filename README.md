# Edge detection implementation outside of RISC-V

## Build
To build this application, you will first need to generate the Makefile using:
```bash
cmake -B build -S .
```

Then, navigate to the build directory and run make:
```bash
cd build && make
```

Shall any problem arise - try to regenerate the Makefile.  
It is now possible to run the program using (in the build directory):
```bash
./app <input_framebuffer_file> <output_framebuffer_file> <algorithm>
```

The algorithm should be either (uppercase) CANNY, PREWITT, ROBERTS, or SOBEL.  
The input framebuffer file should be generated using Python in the next section.  
The output framebuffer file is generated by the application and can be converted back to an image using Python.

## Python utilities
In the `py/` directory there are two helper files made to be used with the application.  

To convert an image file (.png, .jpg) to a framebuffer file able to be read by the application, try:
```bash
python3 png_to_fb.py <image_file> <output_framebuffer_file>
```

To convert a framebuffer file to an image file, try:
```bash
python3 fb_to_png.py <input_framebuffer_file> <output_image_file>
```

## Testing & automatic image generation
Should you want to automatically build, run, and view the images then there is a specific bash script written:
```bash
chmod +x ./run.sh && ./run.sh
```

This script automatically calls `make` and runs every algorithm. Each algorithm will generate a framebuffer output and image file.  
For example, SOBEL will generate `SOBELfb` and `SOBEL.png` in the `build/` directory.
