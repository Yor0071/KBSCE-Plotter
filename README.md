# Onderzoek edge detection
Builden:
`cmake -B build -S .`

In de build directory:
`make`

Uitvoeren:
`chmod +x ./run.sh && ./run.sh`

Dit voert elke algoritme uit en stopt het als `algo.png` in de build directory

# Python
Om een plaatje om te zetten naar een framebuffer of andersom
in `py` directory `python3 png_to_fb.py` of `python3 fb_to_png.py`
